# my-web-app

欲しいものを登録して購入状況を管理する Next.js の Web アプリです。

## 技術スタック

- Next.js App Router
- TypeScript
- Tailwind CSS
- Radix UI

## セットアップ

依存パッケージをインストールします。

```bash
npm install
```

## 開発サーバーの起動

```bash
npm run dev
```

起動後、ブラウザで以下を開きます。

```text
http://localhost:3000
```

## よく使うコマンド

```bash
npm run lint
npm run build
```

`npm run build` は、この環境でも安定して確認できるように Webpack を使う設定にしています。
